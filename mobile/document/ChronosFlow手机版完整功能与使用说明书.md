## 一、产品定位与架构概述

ChronosFlow 手机版是一款专为安卓用户打造的**独立原生时间管理 App**。它解决了移动端用户“时间碎片化”、“频繁在各应用间跳转”以及“忘记打卡”的痛点，融合了**被动自动感知**与**主动极简记录**双轨机制。

### 核心架构亮点
- **Kotlin 原生宿主**：深色全屏沉浸透明状态栏，原生响应式手势适配；
- **Web 前端 SPA 资产**：基于 React 19 + TypeScript + Tailwind CSS，100% 共享 PC 端 NLP 与 AI 认知复盘算法；
- **原生双向通信桥接 (`AppUsageBridge.kt`)**：通过 `@JavascriptInterface` 原生调用 Android 底层 `UsageStatsManager`。

## 二、开箱即用：批处理操作指南

手机版工程目录（`mobile/`）完全对齐选股软件（`ai_stock_tool`）的极速交付范式，标配三大工具：

### 1. 🚀 `【一键安装到手机】.bat`
- **使用方法**：用 USB 数据线将安卓手机连接电脑（确保开启手机“开发者选项”中的“USB 调试”与“允许通过 USB 安装应用”），直接双击运行本脚本；
- **自动化流程**：
  1. 自动寻找系统 ADB 工具；
  2. 自动检测设备状态（若未授权，弹出清晰的中文勾选指引）；
  3. 一键传输安装 `dist/ChronosFlow_v1.0.0_debug.apk`；
  4. 自动在手机屏幕上拉起 ChronosFlow，瞬间开箱体验！

### 2. 📦 `【打包APK】.bat`
- **使用方法**：双击即可全自动完成移动端前端编译与原生 Gradle 编译；
- **输出产物**：自动在 `mobile/dist/` 目录下生成独立的 `ChronosFlow_v1.0.0_debug.apk`（体积仅约 3.8 MB），可直接分发给任何人安装。

### 3. 💻 `【预览手机版】.bat`
- **使用方法**：电脑未连接手机时，双击可在 PC 浏览器中以手机仿真分辨率打开（`http://localhost:5173`）；
- **内置 Mock 降级**：自带模拟微信、B站、知乎等应用时长与权限切换，电脑端也能 100% 体验全部交互。

## 三、核心功能深度详解

### 1. 🤖 系统级其它应用使用时长自动检测与核心应用选定追踪（核心杀手功能）
- **实现原理**：通过安卓系统官方 `PACKAGE_USAGE_STATS` 特别权限与 `UsageStatsManager` API，高精度捕获各 App 前台运行时间；
- **权限向导**：
  - 首次进入时，顶栏显示黄色【待授权】徽章；
  - 点击卡片中的【一键前往开启权限】，系统自动直达安卓【有权查看使用情况的应用】授权列表；
  - 授权后，顶栏实时变为绿色【感知就绪】；
- **选定应用追踪模式 (Focus Mode，告别全量繁杂铺陈)**：
  - **默认聚焦核心应用**：不再一口气把手机中数十个无关系统或后台服务倾倒在界面上，系统默认选定高频应用进行专注追踪；
  - **【选定应用】管理弹窗 (`AppSelectorModal`)**：
    - 支持按中文名称或原生包名实时搜索过滤；
    - 提供“⭐ 推荐常用前4款”、“⏱️ 仅选有时长的应用”、“清空重置”等一键快捷挑选；
    - 多选勾选确认后，主页将仅呈现您所选定的重点 App；
  - **双视图自由切换**：主页顶部支持在【追踪中 (X)】与【全部感知 (Y)】之间一秒切换，既可保持极简日常追踪，也可随时回溯全量数据；
- **单个应用详情深度定制与改名 (`AppDetailModal`)**：
  - **点击卡片直达详情**：点击任意应用条目即弹出沉浸式详情卡片；
  - **自定义应用名称 (改名字 / 别名)**：针对 Android 缺少应用标签或直接暴露 `com.xxx.yyy` 的痛点，用户可自由赋予友好中文名称（如“抖音”、“企业打卡”、“自研工具”），改名后在排行榜与生成的时间流中全局生效；
  - **专注分类定制**：支持自由归类到“开发/工作”、“沟通协作”、“学习/阅读”、“休闲娱乐”、“健康/生活”或“默认/其他”，入流时自动继承；
  - **情绪与精力状态定制 (Mood & Energy)**：支持为该应用设定 6 维情绪与精力状态（平常、专注、心流、疲惫、受挫、分心），生成时间块时自动继承，并同步刷新当天已入流记录与认知精力教练复盘；
  - **专属备忘与目标备注**：支持录入使用提醒（例如“每天刷视频尽量控制在半小时内”），卡片直接呈现轻量备忘小标签；
  - **未知时段入流契约 (Fuzzy Time)**：应用使用时长属于全天零星碎片化使用的累计，一键入流时**默认按照【未知时段】**（`isFuzzyTime: true`，不霸占具体起止钟点）生成时间块，完美解决虚假整段时间霸占时间轴、与日常日程冲突的痛点，同时 100% 精确计入今日总投入与分类周预算；
  - **同日多次增量同步与跨天独立归档**：
    - **增量时长自动识别**：同一天同步一次后，若继续使用某款应用导致时长增加，系统自动计算未同步差值并亮起琥珀色 `同步 +Xm` / `同步新增时长` 按钮，一键将当天时间块平滑更新为最新累计时长（绝不重复堆砌多条记录）；
    - **跨自然日自动重置与历史保护**：底层采用 `UsageEvents` 毫秒级事件流切片与本地自然日隔离（`YYYY-MM-DD`），前一天同步过后第二天自动翻篇为待同步状态，再次同步仅生成今天的新时间块，100% 完整保留前一天的历史记录；
    - **近 7 日回溯与一键批量同步**：顶部日期栏支持切换查看近 7 天任意自然日时长并支持「回今日」，核心时长卡片右侧配备 **「同步前7天记录」** 一键批量同步按钮，可自动遍历近 7 个自然日的追踪应用记录进行补录或增量校准；下方统一由 **「+ 增减应用」** 管理选定追踪名单，交互精简无重复；
  - **数据指标与快捷入流**：清晰呈现今日总时长、原生包名复制、追踪开关切换以及一键生成时间流时间块；
  - **多分类预算与混合场景防重复记说明**：弹窗底部常驻防重复记引导卡片，明确多分类全额计入周预算机制，推荐“应用只记最主要活动、不建议交叉额外补录”的最佳实践，从根源规避时长与预算虚增重合。

### 2. ⚡ 单手操作极简打卡与活跃计时
- **自然语言 NLP 输入**：
  - 支持“开始写代码”、“开始跑步”等实时启动任务；
  - 支持“刚刚看了30分钟微信”、“刚刚刷了半小时抖音”等事后追溯补录，自动识别时长、分类与情绪色彩；
- **活跃任务秒级走字**：全宽呼吸卡片呈现当前进行中任务，支持一键点击停止结算；
- **静音无干扰操作**：全面移除触觉震动反馈，打卡、删除与切换提供清爽静音的交互体验。

### 3. 🏷️ 全链路统一分类依据、专属目标关联与多分类归属体系（Single Source of Truth & Multiple Categories）
为了彻底解决“手动补录分类”与“应用追踪分类”各自分裂、覆盖不足的痛点，系统全面上线并统一了 **10 大全场景分类标准库 (`STANDARD_CATEGORIES`)**，并全面支持**同一记录隶属于多个分类**与**专属目标项目关联**：
- **全链路 100% 相同分类依据**：
  1. ⏰ **手动时补齐 / 编辑弹窗 (`MobileManualModal`)**；
  2. 📱 **应用追踪详情与改名 (`AppDetailModal`)**；
  3. 🤖 **Android 原生底层包名智能映射 (`nativeBridge`)**；
  4. 🧠 **自然语言 NLP 双擎推断规则 (`nlpParser`)**；
  5. 📊 **分类时间投入环形图与周预算 (`storage.ts` + `MobileAnalytics` + `MobileGoals`)**。
- **🌟 同一记录多分类支持 (Multiple Categories Support)**：
  - **核心机制**：不论是应用追踪设置还是手动时补齐，用户均可**同时勾选属于多个标准分类**（如既是“社交/沟通”也是“工作/业务”）；
  - **专属目标项目统一承载个性化分类**：通过绑定专属目标项目（`ProjectGoals`）统一管理个性化长期主题并自动计入专属目标工时，避免与临时自定义分类重复割裂；
  - **彩色胶囊徽章呈现**：时间流与应用卡片上以彩色胶囊展示所有归属分类标签。
- **🌟 应用使用时长百分比统计与占比显示**：
  - **排行榜百分比标注**：每张应用卡片清晰呈现使用分钟数与全天占比（如 `48 分钟 · 占比 35%`）；
  - **详情弹窗双色进度胶囊**：详情弹窗直观展示时长占比进度条与微型高亮胶囊徽章（如 `占比 42%`）。
- **10 大全场景拓展分类与专属微光色彩体系**：
  1. 💼 **`工作/业务`**（#10b981 翡翠绿）：会议、汇报、项目管理、审批对齐；
  2. 💻 **`开发/技术`**（#3b82f6 科技蓝）：代码、架构、Bug排查、Git、部署运维；
  3. 📚 **`学习/提升`**（#8b5cf6 智慧紫）：深度阅读、背单词、网课论文、技能提升；
  4. 💬 **`社交/沟通`**（#06b6d4 交流青）：微信/QQ聊天、好友水群、亲友通话、线下聚会；
  5. 🎮 **`休闲/娱乐`**（#ec4899 活力粉）：单机网游、B站影视、刷短视频、Steam、动漫听歌；
  6. 🏃 **`健康/运动`**（#f59e0b 阳光橙）：健身撸铁、户外慢跑、骑行球类、拉伸瑜伽；
  7. 🏠 **`生活/日常`**（#14b8a6 生活青绿）：通勤出行、做饭用餐、家务打扫、买菜购物、个人琐事；
  8. 🎨 **`创作/灵感`**（#a855f7 灵感紫）：写作博客、绘画作图、视频剪辑、日记灵感；
  9. 💤 **`休息/睡眠`**（#6366f1 静谧蓝）：夜间深度睡眠、午休小憩、放空冥想、歇息泡脚；
  10. 🏷️ **`默认/其他`**（#64748b 板岩灰）：无法归类的综合杂项事务。

## 四、隐私与安全承诺

- **100% 本地存储**：所有时间块、应用使用记录、配置密钥均存储在手机本地沙盒中（LocalStorage / 内部存储）；
- **绝不上云**：应用无需注册账号，不收集任何用户隐私数据；
- **透明合规**：仅在用户显式授权系统权限后才会提取前台应用活跃时长。
