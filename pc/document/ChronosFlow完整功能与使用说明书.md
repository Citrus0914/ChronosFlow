## 1. 项目简介与设计理念

在传统时间管理工具中，繁重的手动表单填写、刻板的类目层级以及机械式的打卡常常给用户带来巨大的心理摩擦，往往导致“用两天就放弃”。

**ChronosFlow（时流）** 从认知心理学和极简交互出发：
- **极简无感（Zero-Friction Recording）**：按下 `Ctrl + K` 或 `Alt + Space` 秒级呼出居中微命令条，口语大白话随手一记，毫秒级解析入库，记完即退；
- **自适应双模解析**：既支持“实时进行中”的专注正向计时，也支持“事后追溯补录”（如“背单词十分钟”、“和客户开会两个小时”），自动提取时长、分类、情绪并净化标题；
- **智能空白断层预警（Smart Gap Alert）**：自动检测距离上一任务结束超过 45 分钟未记录的时间空白，温和提示一键快速补齐，消除全天时间盲区；
- **目标预算与步调健康度（Pace Calculation）**：提供分类每周预算与专属目标（周/月预算），根据周期时间流逝与实际投入进度，智能评估超前（Ahead）、稳步推进（On Track）或滞后（Behind）；
- **AI 认知教练双擎闭环**：支持“周复盘 / 月复盘 / 日复盘”，内置纯本地离线认知规则引擎（无需网络与 API Key），同时兼容 OpenAI 协议远程大模型（DeepSeek、GPT-4o、Claude、本地 Ollama），剖析心流时长、任务切换损耗与行动微建议；
- **100% 隐私安全与数据自治**：所有原始时间流数据纯本地持久化存储（浏览器 LocalStorage），不经过任何第三方服务器中转。

## 2. 快速上手与运行指南（作业演示指引）

本项目已针对作业答辩、评阅或他人快速体验进行了完整的工程优化：

### 2.1 极速双击启动（推荐）
1. 解压收到的压缩包到本地任意文件夹；
2. 确保电脑已安装 **Node.js**（建议 v18 / v20 / v22 或更新版本）；
3. **直接双击根目录下的 `【双击启动ChronosFlow】.bat`**；
   - 脚本会自动检测环境、初次自动安全安装依赖，并自动在默认浏览器中开启应用页面（默认 `http://localhost:1420` 或 Vite 分配端口）；
4. *(可选)* 双击 `【创建桌面快捷方式】.bat`，可在 Windows 桌面生成专属启动图标。

### 2.2 命令行启动方式
```bash
# 1. 安装项目依赖
pnpm install  # 或 npm install

# 2. 启动本地开发服务
pnpm dev      # 或 npm run dev

# 3. 执行自动化测试
pnpm test     # 或 npm test (运行 Vitest 单元测试，38 项断言 100% 通过)

# 4. 生产环境构建
pnpm build    # 执行 TypeScript 类型检查与 Vite 生产打包
```

### 2.3 快速体验丰富演示数据
- **初始启动**：若本地存储为空，系统默认自动预装了近 5 周真实多样的学习、工作与生活数据，方便立即查阅各页面；
- **重置或重新载入**：若您清空了数据或想重置体验，点击顶部导航栏右上角的 **【设置】**（齿轮图标），在“本地数据与演示管理”区域中，点击 **【载入 35 天演示数据】** 按钮，系统将瞬间载入 35 天覆盖 5 大分类、情绪波动与心流的真实记录。

## 3. 核心功能逐项详解

### 3.1 全局极简命令条与自然语言记录引擎 (Command Bar)

- **唤起方式**：在页面任意位置随时按下 **`Ctrl + K`**（Mac 上为 **`⌘K`**）或 **`Alt + Space`**，立即呼出居中微输入框；按 **`Esc`** 秒级隐藏；按顶部导航右上角 `随手记` 按钮亦可唤出。（注：Windows 系统默认将 `Alt + Space` 设为窗口操作控制菜单，若遇浏览器抢占推荐直接使用 `Ctrl + K`）。
- **自然语言解析引擎 (`src/services/nlpParser.ts`)**：支持纯中文数字与常见口语表达。

#### 1. 实时进行中专注模式 (Realtime Focus)
当你要开始专注工作时，输入：
- “*开始写前端架构代码*”
- “*背单词*”
- “*准备跑步*”
- **表现**：系统在时间流顶部启动实时专注卡片，伴随绿色脉动呼吸灯，秒级走字计时；顶部导航栏同步显示“专注中：XXX”。

#### 2. 事后追溯补录模式 (Retroactive Tracking)
事情做完后随时随手补录一笔，支持灵活口语：
- **纯中文数字**：“*背单词十分钟*”、“*冥想五分钟*”、“*背考研真题四十五分钟*”；
- **口语化小时与半小时**：“*做系统设计一个半小时*”（精确解析为 90 分钟）、“*开会两小时*”（120 分钟）、“*看书半小时*”（30 分钟）；
- **跨单位复合时间**：“*修Bug花了1小时20分钟*”、“*写论文两小时十五分*”；
- **起止时刻格式**：“*14:00-15:30 需求评审会*”；
- **标题智能净化**：自动从输入中剔除时间短语，例如输入“背单词十分钟”，入库标题为“背单词”，耗时记录为 10 分钟，杜绝时间词在标题冗余重复。

#### 3. 自然结束会话
- 当有任务正在专注计时时，唤出命令条输入：“*完成了*”、“*做完了*”、“*搞定*”或“*收工*”，即可自动结算归档当前专注事项。

#### 4. 情绪感知与分类归纳
- **情绪状态感知**：输入“*改Bug改吐了*”、“*写代码很爽很有成就感*”、“*开会心力憔悴好累*”，自动捕获并标记“疲惫 (TIRED)”、“专注 (FOCUSED)”或“心流 (FLOW)”；
- **分类归纳**：自动归类到“开发/技术”、“工作/业务”、“学习/提升”、“健康/运动”、“休闲/生活” 5 大核心类目。

### 3.2 主时间流与智能断层感知预警 (Timeline)

- **实时专注卡片**：
  - 置顶展示正在计时的任务；
  - 动态显示 `HH:mm:ss` 耗时、所属分类与情绪标签；
  - 提供【完成任务】与【放弃计时】操作。
- **已完成时间块卡片流**：
  - 垂直展示当日所有完成的时间块；
  - 清晰标注具体起止时刻（如 `14:00 - 15:15`）与总时长（如 `1小时15分钟`）；
  - 专属目标彩色药丸：若关联了专属目标（如“考研英语高频词”），展示专属色彩标牌；
  - 情绪胶囊药丸：直观呈现心流、专注、疲惫等心理状态；
  - 悬浮菜单：支持点击编辑图标修改详情，或点击垃圾桶图标安全删除（带二次防误触确认）。
- **智能空白断层感知（Smart Gap Alert）**：
  - 当检测到上一任务结束与下一任务开始（或当前时间）之间存在 **超过 45 分钟的未记录时间空白**；
  - 时间轴对应位置会渲染温和的橙黄色虚线提醒框：“发现一段 XX 小时 XX 分钟的未记录时间”；
  - 配备 **【快速补录】** 按钮，点击一键自动填入该空白区间的时间，杜绝记录盲区。
- **日期导航**：支持前后切换查看历史任意一天的记录，并可一键回到“今天”。

---

### 3.3 精确补齐过去/记录模态框 (Manual Entry Modal)

点击页面右上角的 **【补齐过去/记录】** 按钮或任意卡片的编辑图标，弹出精准表单：
- **事项名称与起止时间**：自由调整开始时刻与结束时刻，系统自动联动换算总耗时，支持跨天安全处理；
- **5 大事项分类**：5 列大图标直选按钮（`开发/技术`、`工作/业务`、`学习/提升`、`健康/运动`、`休闲/生活`）；
- **专属目标（Goals）药丸直接关联**：
  - 紧随分类下方展示当前所有生效的专属目标药丸；
  - 点击任意目标药丸，一键关联并自动切换为所属大类；再次点击即可取消关联；
- **情绪状态单选**：心流 (FLOW)、专注 (FOCUSED)、平常 (NORMAL)、疲惫 (TIRED)、沮丧 (FRUSTRATED)、分心 (DISTRACTED)；
- **心得笔记/备注**：多行文本框，记录思考与产出。

### 3.4 专属目标与分类时间预算体系 (Goals & Budget)

在顶部导航切换至 **【目标与预算】**：

#### 1. 分类时间预算管理 (Category Budgets)
- 针对 5 大基础大类，自由配置每周目标工时（支持 `-`、`+` 步进按钮或直接键入数值）；
- 进度条直观呈现本周各分类累计工时与每周预算对比。

#### 2. 专属目标项目管理 (Project Goals)
- **创建专属目标**：
  - 设置目标名称（如“攻克考研高数”、“ChronosFlow 开发”）；
  - 设定时间预算类型：**每周预算 (WEEKLY)** 或 **每月预算 (MONTHLY)**；
  - 设定目标预算小时数；
  - 挑选个性化主题颜色（提供 8 款高辨识度色彩标牌）。
- **推进步调健康度算法 (Pace Calculation)**：
  - 系统对比“当前周期的时间流逝比例”与“预算工时实际完成比例”；
  - **超前推进 (Ahead)**：进度显著领先时间流逝，给予正面激励；
  - **稳步推进 (On Track)**：节奏与时间流逝高度吻合；
  - **进度滞后 (Behind)**：预警提醒需加大时间投入。
- **全生命周期维护**：支持目标随时编辑、归档（Archive）隐藏、从归档恢复以及安全移除。

### 3.5 多维数据统计与可视化洞察 (Analytics)

在顶部导航切换至 **【统计洞察】**：
- **周期维度切换**：支持 **日 (DAY)**、**周 (WEEK)**、**月 (MONTH)**、**全部 (ALL)** 4 种维度，并支持前后箭头翻页回溯历史；
- **基础核心效能指标**：
  - 周期总记录时长与时间块数量；
  - **深度心流专注 (Deep Work)**：统计单次时长 ≥ 45 分钟且处于“心流/专注”的高价值时段；
  - **心流进入次数**；
  - **日均专注时长**与活跃天数统计；
- **周期走势柱状图**：
  - **周视图 (WEEK)**：呈现周一至周日 7 天柱状分布图，柱子高度动态按当日投入比例映射，自动高亮峰值天（Peak），并标记心流天；
  - **月视图 (MONTH)**：按周呈现全月走势柱状图（第 1 周至第 4/5 周）；
- **情绪与精力分布**：统计心流、专注、平常、疲惫、沮丧、分心 6 种状态在所选周期内的频次；
- **分类统计条**：各分类累计工时、所占百分比与色彩进度条；
- **时间块卡片明细流**：罗列所选周期内完成的每一项时间块，支持直接删除管理。

### 3.6 AI 个人认知教练复盘 (AI Coach Debriefing)

在顶部导航切换至 **【AI 教练复盘】**：

#### 1. 分级双擎架构
- **引擎 A：本地认知心理学离线规则引擎**：
  - 零网络、无需 API Key，完全在本地执行确定性量化分析；
- **引擎 B：大语言模型（LLM）深度推理引擎**：
  - 支持用户自填兼容 OpenAI 协议的 API（如 DeepSeek-R1/V3、OpenAI、Claude、本地 Ollama 服务）；
  - 结合任务名称与心理状态，给出更具温情与深度的认知复盘。

#### 2. 多周期按需生成
- 支持 **周度复盘 (WEEK)**、**月度复盘 (MONTH)** 与 **日度复盘 (DAY)**；
- **严格遵循按需手动触发**：点击【开始 AI 深度复盘分析】大按钮后才执行一次推理，零静默后台消耗；
- 已生成的报告自动持久化缓存；若期间追加了新记录，提供【重新生成此周期复盘】按钮。

#### 3. 认知复盘报告结构
1. **周期数据摘要指标**：有效记录时长、时间块数量、深度心流专注时长、深度专注占比；
2. **总体节奏与宏观产出洞察 (Executive Summary)**；
3. **深度心流与专注时长分析**；
4. **上下文与任务切换损耗评估 (Attention Residue)**；
5. **情绪与思维卡点剖析 (Friction & Resistance)**；
6. **教练微建议 (Action Steps)**：
   - 日度：明日行动指南 (Tomorrow Steps)；
   - 周度：下周行动调整指南 (Next Week Steps)；
   - 月度：下月目标与精力调优建议 (Next Month Steps)；
7. **精力曲线点评**。

### 3.7 系统设置与本地数据管理 (Settings)

在顶部导航切换至 **【设置】**：
- **API 服务端点与密钥**：
  - API Base URL（支持 DeepSeek、OpenAI、Ollama 本地服务 `http://localhost:11434/v1` 等）；

  - 快速解析模型（默认 `deepseek-chat`）；

- **Token 成本与交互体验控制**：
  - 随手记优先使用本地零消耗规则 Checkbox；
  - 智能空白断层感知提醒 Checkbox；
- **本地数据与演示管理**：
  - **【载入 35 天演示数据】按钮**：一键生成 5 周真实多样的学习、工作、娱乐、运动与心流数据，便于即刻查阅各页面与复盘报告；
  - **【清空所有记录】按钮**：一键清空本地所有时间记录，恢复纯净空白状态；
- **100% 隐私安全保证**：应用运行不依赖任何外部中心化服务器，数据均存放在当前计算机浏览器存储中。
