【第一步：如何一键快速运行项目？】
----------------------------------------------------------------------
1. 确保您的电脑安装了 Node.js 环境（推荐 v18 / v20 / v22 或更高版本，
   若未安装可前往官网下载：https://nodejs.org/ ）。

2. 【最简运行方式】
   直接双击本目录下的：
   👉 【双击启动ChronosFlow】.bat

   脚本会自动检测环境、并在首次运行时自动安装依赖，
   然后自动在您的默认浏览器中开启应用页面（http://localhost:1420）。

3. 【命令行运行方式（如果您习惯使用终端）】
   打开 CMD 或 PowerShell，进入解压目录后依次执行：
   pnpm install   (或 npm install)
   pnpm dev       (或 npm run dev)

----------------------------------------------------------------------
【第二步：如何快速查看最完整的作业效果？（演示推荐）】
----------------------------------------------------------------------
• 初次启动系统时，本地已自动预置了近 5 周（35天）丰富贴近生活的真实数据
  （涵盖技术开发、业务工作、日常学习、健身运动、休闲刷帖与深度心流）。
• 若您此前清空了记录或想重置体验数据：
  1. 点击顶部导航右上角的【设置】图标（齿轮图标）；
  2. 找到“本地数据与演示管理”区域，点击【载入 35 天演示数据】按钮；
  3. 系统将瞬间重新填满 35 天完整真实数据！
• 随后您可以自由体验各页面：
  • 【时间流】：查看时间轴卡片、智能空白断层感知（>45min空白提醒）、呼吸计时卡片；
  • 【目标与预算】：查看大类每周预算与专属目标的周/月预算追踪、步调健康度算法（Ahead/Behind）；
  • 【统计洞察】：查看周度 7 天柱状分布图、月度走势图、心流统计与 6 种情绪分布；
  • 【AI 教练复盘】：体验本地离线规则引擎或远程大模型生成的周度/月度/日度深度复盘与行动建议；
  • 【全局命令条】：随时按下快捷键 [Alt + Space]，体验自然语言随手记账！

【第四步：源代码结构导读】
----------------------------------------------------------------------
• src/components/     : 前端核心 React 视图组件（命令条、时间流、目标、分析、AI复盘、设置等）
