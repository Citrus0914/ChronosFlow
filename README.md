## ✨ 核心亮点

- **⚡ 呼之即来的极简命令条（Command Bar）**：
  - 全局快捷键随时唤起（默认 `Alt + Space`），毫秒级弹出居中微输入框，秒记秒退。
- **🧠 自然语言自适应双模解析**：
  - **实时进行时**：输入“*开始写前端架构代码*”即自动启动当前专注计时与呼吸光晕。
  - **事后追溯**：输入“*背单词十分钟*”、“*做系统架构设计一个半小时*”或“*改Bug改吐了用了一小时*”，自动提取中文数字、时长、任务名称、分类与情绪状态并智能净化标题。
  - **任务结算**：输入“*完成了*”或“*收工*”无缝结束当前活跃会话。
- **🎯 专属目标计划与时间预算体系（Goals & Budget）**：
  - 自定义专属目标与周/月时间预算；
  - 智能计算推进步调（Ahead / On Track / Behind）预警。
- **🌟 AI 个人认知教练每日复盘（AI Coach Debriefing）**：
  - 分级双擎架构：支持本地离线启发式规则引擎与 OpenAI 协议大模型（DeepSeek / GPT-4o / Claude / Ollama）；
  - 深度分析当日心流时长（Deep Work）与任务切换损耗（Attention Residue），生成次日 3 条微习惯行动指南。
- **🔍 智能空白断层感知（Smart Gap Alert）**：
  - 自动检测距离上一任务结束超过 45 分钟的未记录空白，温和提示一键快速补录，拒绝记录断层。
- **🛡️ 100% 隐私安全与数据自治**：
  - 所有原始时间流数据纯本地存储，绝不私自上传云端。

## 🚀 极速开箱与启动

### 方式 1：双击一键运行（推荐评阅与快速体验）
1. 确保电脑已安装 Node.js；
2. **直接双击根目录下的 `【双击启动ChronosFlow】.bat`**；
3. 浏览器将自动打开应用（`http://localhost:1420`）；
4. 进入页面右上角【设置】，点击 **【一键注入 7 天真实演示数据】**，即可秒级体验完整的统计图表与 AI 复盘！

### 方式 2：终端命令启动
```bash
# 安装依赖
pnpm install

# 启动本地开发预览
pnpm dev

# 执行自动化测试 (38项断言 100% 通过)
pnpm test

# 生产环境打包构建
pnpm build
```
