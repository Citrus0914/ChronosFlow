# ⏳ ChronosFlow（时流）

> **AI 驱动的 PC 极简时间管理应用** —— 极简输入・无感记录・深度洞察・100% 隐私安全

---

## ✨ 核心亮点

- **⚡ 呼之即来的极简命令条（Command Bar）**：
  - 全局快捷键随时唤起（默认 `Alt + Space`），毫秒级弹出居中微输入框，秒记秒退。
- **🧠 自然语言自适应双模解析**：
  - **实时进行时**：输入“*开始写前端架构代码*”即自动启动当前专注计时。
  - **事后追溯**：输入“*刚刚花了40分钟开架构评审会*”或“*改Bug改吐了用了一小时*”，自动提取时长、任务名称、分类与情绪状态。
  - **任务结算**：输入“*完成了*”或“*收工*”无缝结束当前活跃会话。
- **🌟 AI 个人认知教练每日复盘（Debriefing）**：
  - 深度分析当日时间流去向、深度心流时长（Deep Work）与任务切换损耗（Attention Residue）；
  - 挖掘情绪阻力卡点（Friction Points），并生成针对次日的精准微习惯行动指南。
- **🔍 智能空白断层感知（Smart Gap Alert）**：
  - 自动检测距离上一任务结束超过 45 分钟的未记录空白，温和提示一键快速补录，拒绝记录断层。
- **🛡️ 100% 隐私安全与分级双擎**：
  - 所有原始时间流数据纯本地存储，绝不私自上传云端；
  - 快速解析与本地规则离线可用；支持用户自填 OpenAI / DeepSeek / Claude / Ollama API Key。

---

## 🛠️ 技术架构

- **核心框架**：Tauri v2 (Rust) + React 19 + TypeScript + Vite 8
- **样式与组件**：Tailwind CSS v4 + Lucide Icons
- **状态管理**：Zustand 5
- **解析引擎**：分级双擎（本地时间正则快速提取器 + 兼容 OpenAI 协议的 LLM）
- **测试框架**：Vitest 5
