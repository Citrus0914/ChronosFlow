【第一步：如何一键快速运行项目？】
----------------------------------------------------------------------
1. 确保您的电脑安装了 Node.js 环境（推荐 v18 / v20 / v22 或更高版本，
   若未安装可前往官网下载：https://nodejs.org/ ）。

2. 【最简运行方式】
   直接双击本目录下的：
   👉 【双击启动ChronosFlow】.bat

   脚本会自动检测环境、并在首次运行时自动安装依赖，
   然后自动在您的默认浏览器中开启应用页面（http://localhost:1420）。

3. 【命令行运行方式（如果您习惯使用终端）】
   打开 CMD 或 PowerShell，进入解压目录后依次执行：
   pnpm install   (或 npm install)
   pnpm dev       (或 npm run dev)

----------------------------------------------------------------------
【第二步：如何快速查看最完整的作业效果？（强烈推荐）】
----------------------------------------------------------------------
因为新启动的应用默认是空白数据，为了让您无需手动记录几天就能立即评测所有功能：

1. 应用启动并在浏览器打开后，点击右上角的【设置】图标（齿轮图标）；
2. 找到“数据备份与演示”区域，点击【一键注入 7 天真实演示数据】按钮；
3. 系统将瞬间载入 7 天包含深度心流（Deep Work）、任务切换损耗、情绪波动、
   以及专属目标预算的完整真实数据！
4. 随后您可以自由体验：
   • 【时间流】：查看时间轴、智能断层感知预警（>45min空白）、呼吸计时卡片；
   • 【专属目标】：查看考研、开发等目标的周/月预算追踪与步调健康度算法（Ahead/Behind）；
   • 【统计洞察】：查看多维心流时长分析、情绪热力分布、24小时精力柱状图；
   • 【AI 复盘】：体验本地规则引擎或大模型双擎生成的每日深度复盘报告与行动指南；
   • 【全局命令条】：随时按下快捷键 [Alt + Space]，体验自然语言随手记账！

【第四步：源代码结构导读】
----------------------------------------------------------------------
• src/components/     : 前端核心 React 视图组件（命令条、时间流、目标、分析、AI复盘等）
• src/services/       : 核心逻辑层（自然语言双模解析引擎、AI复盘双擎、演示数据生成等）
