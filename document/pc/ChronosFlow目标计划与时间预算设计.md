## 一、系统架构与双轨模型 (Dual Tracking Architecture)

为了兼顾“全局宏观配比”与“阶段性重点突破”，ChronosFlow 采用分类预算与专属项目目标双轨并行：

1. **分类周预算 (Category Weekly Budgets)**：
   - 覆盖 6 大通用分类（开发/技术、工作/业务、学习/提升、健康/运动、休闲/生活、其他工作）；
   - 支持动态切换预算性质：
     - **至少投入达标型 (`AT_LEAST`)**：如学习 ≥ 10h、开发 ≥ 20h；
     - **不超过上限克制型 (`AT_MOST`)**：如休闲娱乐 ≤ 8h，防范时间黑洞。
   - 随手调控：点击即改目标小时数与启用开关。

2. **专属目标项目 (Project Goals / Milestones)**：
   - 针对具体战役（如“ChronosFlow核心重构”、“考研英语”、“软考冲刺”）设立独立卡片；
   - 包含专属主题色、归属主分类、目标时长（周度目标 `WEEKLY` 或总里程碑 `TOTAL`）、智能关联关键词（`keywords`）；
   - 支持一键启动“⚡ 专注此项目”专属实时计时，支持编辑、归档与安全删除。

## 二、智能节奏健康度算法 (Pace & Health Algorithm)

通过动态比对当前周的时间流逝进度与实际时间投入比例，实现智能状态预警：

$$P_{\text{time}} = \frac{\text{当前自然周已过去分钟数}}{10080 \text{ 分钟 (7 天)}}$$
$$P_{\text{actual}} = \frac{\text{实际累计分钟数}}{\text{周目标分钟数}}$$

| 预算类型 | 触发条件 | 状态 | 徽章呈现 | 含义 |
| :--- | :--- | :--- | :--- | :--- |
| **至少投入型** | $P_{\text{actual}} \ge 1.0$ | `COMPLETED` | 🏆 已达成 | 超额达成周目标 |
| | $P_{\text{actual}} \ge P_{\text{time}} + 0.1$ | `AHEAD` | 🟢 进度超前 | 投入进度领先于时间流速 |
| | $P_{\text{actual}} \ge P_{\text{time}} - 0.15$ | `ON_TRACK` | 🔵 节奏良好 | 投入节奏稳步与时间匹配 |
| | $P_{\text{actual}} < P_{\text{time}} - 0.15$ | `BEHIND` | 🟠 进度滞后 | 投入落后于时间流速，需提高优先级 |
| **不超过上限型** | $P_{\text{actual}} > 1.0$ | `EXCEEDED` | 🔴 已超预算 | 超出上限，警惕时间赤字 |
| | $P_{\text{actual}} > P_{\text{time}} + 0.12$ | `WARNING` | ⚠️ 消耗过快 | 消耗速度快于时间流速 |
| | 其余 | `HEALTHY` | 🟢 克制健康 | 保持良好克制 |

## 三、极简无感随手记与智能关联 (NLP Engine)

1. **大白话自动语义推断**：随手记包含项目关键词（如“写时流代码 2小时”）时，自动关联到对应专属项目；
2. **显式 `#标签` 支持**：输入 `#ChronosFlow 修复Bug`，系统精准绑定该项目并清洗掉多余标签前缀；
3. **补齐记录弹窗联动**：`ManualEntryModal` 自动呈现项目选择药丸，点击可一键带入主分类与项目关联；
4. **全链路色彩标识**：在时间轴（`TimelineView`）与统计列表（`AnalyticsView`）中呈现对应项目的主题色微光徽章。

## 四、AI 教练深度复盘协同 (AI Debrief Integration)

在周度 AI 认知复盘分析中，系统自动将当前已启用的分类预算达成情况注入评估模型，自动针对超支或滞后分类给出针对性的**精力重分配与下周行动建议**，达成闭环。
