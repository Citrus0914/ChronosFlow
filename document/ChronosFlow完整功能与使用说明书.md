## 1. 项目简介与设计理念

在传统时间管理软件中，繁重的手动表单填写、复杂的类目选择和冷冰冰的打卡机制往往带来巨大的心理阻力，导致“记了三天就弃用”。

**ChronosFlow（时流）** 旨在打破这一桎梏。它结合现代前端交互与轻量级自然语言解析，重新定义了时间管理：
- **极简无感（Zero-Friction Recording）**：无论你何时在做什么，按下 `Alt + Space` 呼出居中微输入框，用大白话输入一句话即可完成记录，毫秒级响应，记完即走；
- **自适应双模感知**：既支持“实时进行中”的专注倒计时，也支持“事后追溯补录”（如“背单词十分钟”、“和客户开会两个小时”），自动解析时长、分类和情绪；
- **智能空白断层预警（Smart Gap Alert）**：自动感知长达 45 分钟未记录的失控空白，温和提示一键补录，拒绝记录断层；
- **认知教练闭环（Cognitive Coaching Loop）**：不只是记账，内置 AI 认知教练与本地规则引擎，深度剖析深度心流（Deep Work）、注意力切换损耗（Attention Residue），并输出针对明天的微习惯行动建议；
- **100% 隐私安全与数据自治**：所有时间数据纯本地持久化存储（LocalStorage），绝不向任何第三方云端上报行为数据；支持自填大模型 API Key（兼容 OpenAI / DeepSeek / Claude / 本地 Ollama）。

## 2. 快速上手与开箱体验（作业演示指引）

本项目已针对作业答辩、评阅或他人快速体验进行了完整的开箱优化。无需复杂配置，只需以下简单步骤：

### 2.1 极速双击启动（推荐）
1. 解压收到的压缩包到任意本地文件夹；
2. 确保电脑已安装 **Node.js**（建议 v18+ / v20+ / v22+）；
3. **直接双击根目录下的 `【双击启动ChronosFlow】.bat`**；
   - 脚本会自动检测环境、初次自动安全安装依赖，并自动在默认浏览器中开启应用页面（默认 `http://localhost:1420` 或 Vite 分配端口）；
4. *(可选)* 双击 `【创建桌面快捷方式】.bat`，可在 Windows 桌面生成一键无弹窗启动图标。

### 2.2 开发者命令行启动
如果您习惯在终端下运行：
```bash

pnpm install  # 或 npm install / yarn

# 2. 启动本地开发服务
pnpm dev      # 或 npm run dev

# 3. 执行自动化测试
pnpm test     # 或 npm test (运行 Vitest 自动化单元测试，38项用例)

# 4. 生产环境构建
pnpm build    # 执行 TypeScript 编译与 Vite 生产打包
```

为了方便老师、同学或评测人员立即查看完整效果，而不需要手动花好几天记时间：
1. 打开应用后，点击右上角设置图标（齿轮）进入 **系统设置** 页面；
2. 在“数据备份与演示”区域，点击 **【一键注入 7 天完整真实演示数据】** 按钮；
3. 注入成功后，应用将瞬间填满近 7 天真实多元的学习、工作、健身、深度心流、情绪波动与专属目标预算数据；
4. 随后可自由切换顶部导航栏的 **【时间流】**、**【专属目标】**、**【统计洞察】** 和 **【AI 复盘】**，体验完整的数据流动与图表渲染！

### 3.1 全局极简命令条与自然语言记录引擎

- **唤起方式**：在页面任意位置随时按下 **`Alt + Space`**，立即在屏幕中央弹出高聚焦微输入框；按 **`Esc`** 秒级关闭。
- **自适应双模解析引擎 (`nlpParser.ts`)**：支持强大而地道的中文大白话口语表达。

#### 模式一：实时进行时（Realtime Timer）
当你正要开始专注时，输入：
- “*开始写前端架构代码*”
- “*背单词*”
- “*准备跑步*”
- 引擎识别到动词或无过去式修饰，**立即在时间流顶部启动实时计时卡片**，伴随淡蓝色呼吸光晕脉动，秒级动态走字。

#### 模式二：事后追溯补录（Retroactive Tracking）
事情做完后随时补一笔，系统支持口语化数字与自然表达：
- **纯中文数字**：“*背单词十分钟*”、“*冥想五分钟*”、“*背考研真题四十五分钟*”；
- **口语化小时与半小时**：“*做系统设计一个半小时*”（解析为 90 分钟）、“*开会两小时*”（120 分钟）、“*看书半小时*”（30 分钟）；
- **跨单位复合时间**：“*修Bug花了1小时20分钟*”、“*写论文两小时十五分*”；
- **具体起止时刻**：“*14:00-15:30 需求评审会*”；
- 系统会自动提取耗时，以当前时间往前倒推开始时刻，并**智能净化标题**（例如“背单词十分钟”提取出干净的标题“背单词”，杜绝时间词在标题中冗余重复）。

#### 模式三：快捷任务结算
- 当前有任务正在计时时，只需呼出命令条输入：“*完成了*”、“*做完了*”、“*搞定*”或“*收工*”，即可自动将当前正在计时的任务优雅归档结算。

#### 智能情绪与分类归纳
- **情绪感知**：输入“*改Bug改吐了*”、“*写代码很爽很有成就感*”、“*开会心力憔悴好累*”，自动捕获并标记“疲惫”、“专注”、“轻松”或“兴奋”标签；
- **分类归纳**：自动归类到“开发/技术”、“工作/业务”、“学习/提升”、“健康/运动”、“休闲/生活” 5 大基础大类。

### 3.2 主时间流与智能断层感知 (Timeline View)

时间流主页面直观呈现全天的时间轨迹：
1. **活跃计时卡片**：
   - 处于专注状态的任务置顶高亮展示；
   - 包含实时跑动的 `HH:mm:ss` 计时器、分类标识与情绪药丸；
   - 提供快速“完成任务”与“放弃计时”按钮。
2. **已完成时间块卡片**：
   - 清晰标明具体起止时间段（如 `14:00 - 15:15`）与总耗时长（如 `1小时15分钟`）；
   - 专属目标彩色药丸：如果该事项关联了专属目标（如“考研英语词汇”），会显示专属颜色徽标；
   - 情绪胶囊：直观反映执行该事项时的心态；
   - 悬浮操作菜单：支持随时“编辑详情”与“安全删除”。
3. **智能空白断层感知（Smart Gap Alert）**：
   - 如果上一项任务结束到下一项任务开始（或当前时间）之间存在 **超过 45 分钟的未记录空白**；
   - 系统将在时间轴对应位置以温和的橙黄色虚线框展示：“发现一段 1 小时 20 分钟的未记录时间”；
   - 提供 **【快速补录】** 快捷按钮，点击直接带入该空白区间的时间，帮助用户彻底消灭全天时间盲区。
4. **历史日期回溯**：顶部提供快速日期切换，支持随时查看过去的任意一天。

### 3.3 精确手动记录与编辑 (Manual Entry Modal)

点击页面右上角的 `+ 记一笔` 按钮或点击任意历史卡片的编辑按钮，即可打开精准补录弹窗：
- **事项名称与起止时间**：支持精准到分钟的起止时间选择，系统自动联动计算总时长，且内置跨天检测；
- **5 大核心分类**：5 列整齐排布的大图标直选按钮（开发/技术、工作/业务、学习/提升、健康/运动、休闲/生活）；
- **专属目标（Goals）药丸直接关联**：
  - 如果用户在目标系统中创建了专属项目，弹窗中会直接展示目标标签药丸；
  - 点击任意目标药丸，一键绑定并自动联动分类；再次点击即可取消关联；
- **情绪状态单选**：专注、轻松、疲惫、焦虑、兴奋可选；
- **心得笔记/备注**：支持多行文字输入，记录该事项的关键产出或思考。

### 3.4 专属目标计划与时间预算体系 (Goals View)

单纯记录时间往往缺乏方向感。ChronosFlow 引入了“时间预算”理念：
1. **创建专属目标**：
   - 设置目标名称（如“攻克考研高数”、“ChronosFlow 独立开发”）；
   - 设定时间预算：支持**周预算**（如每周 15 小时）或**月预算**（如每月 60 小时）；
   - 自定义色彩标牌：提供多种主题色药丸，便于在全系统一眼识别。
2. **实时预算进度与消耗可视化**：
   - 卡片直观展示“已投入时长 / 预算总时长”，配备高雅的动态渐变进度条；
3. **智能健康度与推进步调算法（Pace Calculation）**：
   - 系统根据当前时间处于周期（周或月）的百分比，与时间预算实际消耗百分比进行数学比对；
   - **超前推进（Ahead）**：投入进度远快于时间流逝，给予正向鼓舞；
   - **稳步推进（On Track）**：节奏良好，与时间进度高度吻合；
   - **进度滞后（Behind）**：自动发出预警，提示本周/本月需加大专注投入；
4. **归档与维护**：支持目标随时启用、停用归档与安全移除。

### 3.5 多维数据统计与深度洞察 (Analytics View)

将原始的时间数据提炼为极具指导意义的认知图表：
- **多周期灵活切换**：支持“今日”、“本周”、“本月”以及“自定义日期范围”快速切换；
- **核心效能三指标**：
  1. **总记录时长**：全天被明确追踪的总时间与覆盖率；
  2. **深度专注时间（Deep Work）**：单次持续超 40 分钟且处于“开发/学习”等核心分类的高价值心流总计；
  3. **注意力切换损耗（Attention Residue）**：统计频繁在碎片任务间切换产生的精力摩擦损耗；
- **分类时间占比可视化**：各类别投入占比直观呈现，一眼看出时间是否倾斜于真正重要的事项；
- **情绪与精力状态分布**：专注 vs 疲劳时长比，监测是否进入疲劳工作周期；
- **24 小时全天精力分布柱状图**：按 0:00 ~ 24:00 时间段统计每小时的专注密度，直观找出自己的“每日黄金心流时段”。

### 3.6 AI 个人认知教练每日复盘 (AICoachView)

复盘是提升时间感知的关键一步。ChronosFlow 提供业内独创的**分级双擎认知教练**：

#### 双引擎自适应保障：
- **引擎 A：本地启发式认知算法引擎（Offline Heuristic）**：
  - 零网络、零配置要求；
  - 即使不填任何 API Key，也能依据全天深度工作时长、任务切换频率、情绪数据，瞬时生成严谨精准的量化分析与复盘报告！
- **引擎 B：大语言模型（LLM）深度教练引擎**：
  - 支持用户自填兼容 OpenAI 接口标准的 API Key（如 OpenAI GPT-4o、DeepSeek-V3/R1、Claude、或本地离线部署的 Ollama 等）；
  - 结合全天详细事项上下文，提供更具温情与深度认知视角的个性化点评。

#### 认知复盘报告四大结构：
1. **今日专注与心流画像**：深度剖析今日高产出时间段与注意力纯度；
2. **精力卡点与注意力损耗诊断**：精准指出导致疲惫、拖延或频繁切换任务的核心诱因；
3. **专属目标对齐度评估**：检验全天时间分配是否偏离预定的周/月目标；
4. **针对明天的 3 条微习惯行动指南（Actionable Micro-Habits）**：拒绝大而空的说教，给出具体到几点几分做什么的微小改善建议。

### 3.7 系统设置与 100% 本地隐私保障 (Settings View)

- **100% 纯本地离线隐私**：应用所有数据直接存放在浏览器本地的 `LocalStorage`，不经过任何外部服务器中转，真正保障隐私安全；
- **AI 模型配置**：支持自定义 Base URL、API Key 与 Model 名称，保存后即刻生效；
- **数据导入与导出**：一键导出 JSON 格式的完整数据备份，随时在不同电脑间无损迁移；
- **演示数据一键载入**：随时一键注入 7 天真实多元的演示数据集，方便教学、演示与作业答辩；
- **数据重置与清理**：提供防手抖的二次确认重置机制。
